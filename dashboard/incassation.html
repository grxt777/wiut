Как считается

Срок визита и сумма загрузки — из ML-прогноза спроса (XGBoost) по истории транзакций: выезд, пока с вероятностью 99% хватает остатка, загрузка — на цикл с тем же запасом. Банкоматы с остатком < 20% едут в любом случае; для банкоматов без прогноза — пороги остатка (< 20% / < 40%). Рейс выходит из филиала «Инкассация = 1» своего вилоята. Даты — рабочие дни по 8 часов, начиная с сегодня (UTC+5).
