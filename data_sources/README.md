# Источники данных

| Файл | Что внутри | Источник | Лицензия / условия |
|---|---|---|---|
| `cbu_atms_tashkent.json` | 1 589 банкоматов г. Ташкента от 25 банков: адрес, район, координаты, платёжные системы | Открытый реестр «Банкоматы» Центрального банка РУз (cbu.uz), выгрузка 10.10.2026, через репозиторий [zzzumraddd/karta](https://github.com/zzzumraddd/karta) | Открытые данные ЦБ РУз |
| `osm_spots_tashkent.json` | 804 места массового скопления людей: рынки, ТЦ, метро, супермаркеты | OpenStreetMap, Overpass API (октябрь 2026), через [zzzumraddd/karta](https://github.com/zzzumraddd/karta) | ODbL 1.0 © участники OpenStreetMap |

Как используются:
- банкоматы **Ipak Yo'li Bank** (144 устройства) — реестр сети в демо (`api/analytics/registry.py`);
- банкоматы других банков — признак конкурентной плотности в гео-скоринге (`api/analytics/geo.py`);
- места скопления людей — гео-скоринг локации 0–10 (`api/analytics/geo.py`).

Транзакции, остатки, кассеты, серийные номера и модели устройств — синтетические (`api/analytics/generator.py`).
